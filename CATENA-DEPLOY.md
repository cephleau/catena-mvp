## Deploy to Netlify (5 minutes)

### Option 1: Drag & Drop (Fastest)

1. Go to **https://app.netlify.com**
2. Sign in with your account
3. **Drag and drop** `catena-landing.html` onto the page
4. Done! Site goes live immediately

### Option 2: Connect Git Repository

1. Create a new folder `/catena-site`
2. Put `catena-landing.html` in there as `index.html`
3. Push to GitHub
4. Connect to Netlify
5. Deploy

### Option 3: Use Netlify CLI

```bash
npm install -g netlify-cli
netlify deploy --prod --dir=. --file=catena-landing.html
```

## Point Domain to Netlify

1. Get your Netlify domain (e.g., `xxx.netlify.app`)
2. Go to **Netlify Settings → Domain**
3. Add custom domain: `catenalanguagepartners.com`
4. Update DNS:
   - Nameserver: Netlify's nameservers
   - Or: Point A record to Netlify IP
