## 🔄 How Auto-Deploy Works

Netlify is connected to your GitHub repository. When you:

```bash
cd /Users/cephleau/.openclaw/workspace/catena-mvp
git add .
git commit -m "Your changes"
git push origin main
```

Netlify automatically:
1. Detects the push to main
2. Clones the latest code
3. Runs: `npm run build`
4. Deploys the `.next` directory
5. Makes it live (2-5 minutes)
