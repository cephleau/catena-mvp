## 🌐 DOMAIN SETUP

### Current Status
- Domain: cephleau.com (you own this)
- Nameservers: Currently pointing to [CHECK YOUR REGISTRAR]

### To Point to Netlify
1. [ ] Go to Netlify → Site settings → Domain management
2. [ ] Note Netlify nameservers (provided by Netlify)
3. [ ] Go to your domain registrar (likely Cloudflare or GoDaddy)
4. [ ] Update nameservers to Netlify's nameservers
5. [ ] Wait 5-15 minutes for DNS propagation
6. [ ] Test: Open cephleau.com in browser
7. [ ] Should see your website ✓

### Nameserver Format
Netlify will provide 4 nameservers like:
```
dns1.p06.nsone.net
dns2.p06.nsone.net
dns3.p06.nsone.net
dns4.p06.nsone.net
```
